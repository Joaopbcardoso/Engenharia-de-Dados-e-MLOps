# Aula 4: Pipeline de classificação

O pipeline gera dados sintéticos, treina um classificador, calcula métricas e cria um relatório PDF e um gráfico.

## Dependências

```powershell
python -m pip install -r "Aula 4/requirements.txt"
```

## Executar

```powershell
python "Aula 4/pipeline.py"
```

Os gráficos e relatórios gerados são arquivos locais e não são versionados.
