# Aula 3: Predição de falhas

Esta aula treina dois modelos para compressor e disponibiliza uma simulação em Streamlit.

## Dependências

```powershell
python -m pip install -r "Aula 3/requirements.txt"
```

## Executar

```powershell
python "Aula 3/treinar_modelo.py"
streamlit run "Aula 3/teste_compressor.py"
```

O primeiro comando gera os arquivos `.joblib` usados pelo segundo. Eles são arquivos locais de execução e não devem ser enviados ao repositório.
