# Aula 2: Modelagem de dados

Os scripts criam consultas e modelos analíticos usando DuckDB e pandas.

## Dependências

```powershell
python -m pip install -r "Aula 2/requirements.txt"
```

## Executar

```powershell
python "Aula 2/modelagem.py"
python "Aula 2/exercício/modelagem-expandida.py"
```

Os scripts podem gerar banco, planilha e relatórios CSV locais. Esses arquivos são artefatos de execução e estão no `.gitignore`.
