# Aula 5: Integração de dados

Esta atividade trabalha com os dados de clientes do CRM e os envios brutos disponíveis nesta pasta.

## Dependências

```powershell
python -m pip install -r "Aula 5/requirements.txt"
```

## Executar

```powershell
python "Aula 5/main.py"
```

Os arquivos `clientes_crm.json` e `envios_brutos.csv` são as entradas da atividade.
